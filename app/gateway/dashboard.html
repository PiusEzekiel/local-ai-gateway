Enter the gateway's access token to view your private jobs and controls.

This is the token generated by your Local AI Gateway — not your ChatGPT login or an OpenAI API key.

Where do I find my token?

Start Local AI Gateway in Pinokio, then open PowerShell in its app folder:

powershell -NoProfile -ExecutionPolicy Bypass -File .\show-token.ps1

Copy the token shown in your own terminal and paste it above. Keep it private; anyone with it can access this gateway.

◈

The token stays in this browser tab's session storage. Disconnect clears it from the tab; it does not stop the gateway or rotate the server token.
